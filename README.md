# SPA Polignac Former Website

This project is the former website of the SPA of Polignac (an animal shelter), which I developed voluntarily during my final year of high school. The website fully meets the requirements set by the shelter, providing an intuitive interface that allows staff to manage the database independently (including adding, editing, and deleting animal profiles) as well as to publish and update articles. The main objective was to deliver a simple, efficient, and long-lasting digital solution tailored to the specific needs of the shelter.
